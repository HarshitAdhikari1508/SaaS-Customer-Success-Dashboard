📊 SaaS Customer Success & Risk Analysis Dashboard
🚀 Project Overview
This project features a high-fidelity Power BI Dashboard designed for Customer Success Managers (CSMs). In the SaaS industry, retaining customers is as important as acquiring new ones. This dashboard provides actionable insights into customer health, allowing for proactive churn prevention and strategic account management.

🛠️ Tech Stack & Skills Demonstrated
Business Intelligence: Power BI Desktop

Data Modeling: MS Excel (Complex SaaS Simulation Dataset)

UI/UX Design: Professional Dark Mode Interface with High-Contrast Neon Visuals

Analytics: Churn Prediction, Health Scoring, and Revenue Risk Assessment

📈 Key Metrics & KPIs
Total Revenue (MRR): Monitoring the monthly recurring revenue across the portfolio.

High-Risk Customers: A real-time alert system identifying customers with a Health Score < 50.

Customer Health Index: A composite metric tracking usage, support tickets, and sentiment.

Support Ticket Correlation: Visualizing the relationship between technical issues and account dissatisfaction.

Plan Distribution: Segmentation of revenue and risk across Enterprise, Professional, and Basic tiers.

💡 Key Features
Predictive Alert System: A dedicated Neon Red KPI Card for "At-Risk" customers to trigger immediate intervention.

Interactive Slicers: Full-page filtering by Subscription Plan for granular performance analysis.

Drill-Down Risk Table: Detailed view of specific accounts requiring urgent CSM outreach.

Executive Dark Theme: Modern, high-impact UI designed for clarity and professional presentation.

📂 Project Structure
